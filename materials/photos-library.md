# Photo library — Trends 2027 image & link repository

Converted from `materials/original/photos-library.xlsx` (sheet `Repository`).

One row per photograph used on the two trend pages. **Layer name** matches the image layer name
in the Figma redesign, which is how each row is tied to an image on the site. **Link** is the
destination the image navigates to on click; **Caption** is the text shown on the hover/focus flip.
Two rows read "no caption needed, just direct navigation to hyperlink" — those images link but do
not flip.
